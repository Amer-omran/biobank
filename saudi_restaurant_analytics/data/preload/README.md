# ملفات التحميل التلقائي

ضع هنا ملف بيانات (CSV أو Excel) مثل `train_split_platform.csv`.
عندما تبدأ المنصة بقاعدة بيانات فارغة (مثلًا بعد إعادة تشغيل Streamlit Community Cloud)
تستورد كل ملفات هذا المجلد وتحللها تلقائيًا، واسم مجموعة البيانات هو اسم الملف.

- لا تضع هنا بيانات شخصية أو سرية: المستودع عام.
